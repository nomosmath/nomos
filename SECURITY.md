# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.5.x | Yes |
| 0.4.x | Yes |
| < 0.4 | No |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Email: security@nomosmath.xyz

We will acknowledge within 48 hours and provide a timeline for fix within
5 business days.

## Scope

- Consensus logic (slashing, validation, quorum)
- Proof verification correctness
- State trie integrity
- P2P message authentication

## Out of Scope

- Denial of service (unless amplified)
- Social engineering
- Vulnerabilities in dependencies (report upstream)
